# Colaborar

El código está publicado con derechos reservados. Antes de enviar código o recursos, abre un issue para acordar el alcance y las condiciones de uso de tu contribución. No envíes materiales de terceros sin permiso verificable.

Para proponer una corrección: crea una rama desde `main`, instala el proyecto con `python -m pip install -e .`, ejecuta `python -m unittest discover -s tests -v` y abre un Pull Request con el problema, la solución y las pruebas realizadas. No incluyas proyectos de clientes, coordenadas sensibles ni resultados de campo.
