# Preguntas frecuentes

**¿Por qué no aparece el EXE en el ZIP del repositorio?** El código fuente se compila en Windows. Descarga la Release para obtener el EXE.

**¿Dónde quedaron mis resultados?** Pulsa **Abrir resultados**. Por defecto están junto al EXE o en `%LOCALAPPDATA%\SPT Go Portable\Resultados` si la carpeta del EXE está protegida.

**¿Por qué se ve una advertencia de Windows?** El ejecutable no está firmado. Comprueba la URL oficial y la suma SHA-256. No desactives antivirus.

**¿Por qué no se carga un KML/KMZ?** Comprueba que el archivo exista, tenga la extensión correcta y contenga un documento KML válido. El archivo original se mantiene intacto.

**¿Por qué no aparece un punto de potencial al 100%?** El 100% se reserva al pozo auxiliar de corriente. La circunferencia del 100% sí se dibuja.

**¿Se necesita internet?** La generación local no. Descargar el EXE y compilar desde código sí requieren acceso a las fuentes correspondientes.
